## 1. 基本資訊
- **指令名稱**：`ABS` (Absolute Value)
- **指令類別**：基礎運算 (Basic Arithmetic)
- **格式**：R-type (`opcode = 0001011` / `0x0B`)

## 2. 語意與算式
- **公式**：`rd = |rs1|`
- **運算元**：一元運算，使用 `rs1` 暫存器。
- **結果寫回**：`rd` 暫存器。

## 3. 邊界與溢位處理
- 當 `rs1 = -2^31` (`-2147483648` / `0x80000000`) 時，由於正數最大值僅為 `2^31 - 1` (`2147483647`)，絕對值計算會發生 32-bit 二補數溢位，低 32 位元 Wrap-around 結果為 `-2147483648` (`0x80000000`)。

## 4. 測試向量 (Test Vectors)
- `rs1 = -5` $\rightarrow$ `rd = 5`
- `rs1 = 0` $\rightarrow$ `rd = 0`
- `rs1 = -2147483648` $\rightarrow$ `rd = -2147483648` (邊界溢位)

## 5. 硬體實現提示
- 符號位元判斷（Sign Bit Mask） + 減法器 / 取二補數電路，或以 XOR 加 1 實現。
